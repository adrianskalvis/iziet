# Ticketshop

**Kam:** SIA "FIRST ROW TECHNOLOGY", Ticketshop (kontakts ticketshop.lv lapā).

**Temats:** Atļauja rādīt Ticketshop pasākumus lietotnē Iziet

Labdien!

Veidoju bezmaksas mobilo lietotni Iziet (iziet.lv), kas palīdz cilvēkiem Latvijā atrast pasākumus. Katram pasākumam lietotnē ir poga "Pirkt biļetes", kas ved tieši uz ticketshop.lv.

Jūsu noteikumu 5.2. punkts ierobežo datu atkārtotu izmantošanu, tāpēc lūdzu atļauju rādīt publiski redzamo informāciju (nosaukums, datums, vieta, cena, attēls) no ticketshop.lv. Mēs ievērojam robots.txt, lasām datus ne biežāk kā reizi 6 stundās, vienmēr norādām avotu un izņemsim jebkuru pasākumu pēc jūsu lūguma.
